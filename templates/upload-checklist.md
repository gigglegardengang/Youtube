# Upload checklist

- [ ] Final video exported and watched all the way through
- [ ] Title (under ~60 characters, clear and clickable)
- [ ] Description (first two lines matter most; include links)
- [ ] Tags and category
- [ ] Thumbnail uploaded (1280x720)
- [ ] Captions / subtitles checked
- [ ] Audience setting: "made for kids" chosen correctly
- [ ] End screen and cards added
- [ ] Added to the right playlist
- [ ] Scheduled or published
