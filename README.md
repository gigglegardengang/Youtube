# Giggle Garden YouTube

The home base for planning, writing and tracking our YouTube videos.

## Folder layout

| Folder | What goes here |
| --- | --- |
| `ideas/` | Video ideas, one file each, plus `backlog.md` for quick notes |
| `scripts/` | Finished or in-progress scripts, named `YYYY-MM-DD-short-title.md` |
| `thumbnails/` | Thumbnail images and notes (keep files under ~5 MB) |
| `assets/` | Reusable music, sound effects, logos and graphics |
| `templates/` | Copy these to start a new idea, script or upload checklist |
| `published/` | One file per published video: link, title, description, tags, notes |

## Making a new video

1. Jot the idea in `ideas/backlog.md`, or copy `templates/idea.md` into `ideas/`.
2. When it's ready to write, copy `templates/script.md` into `scripts/`.
3. Before uploading, go through `templates/upload-checklist.md`.
4. After it's live, copy `templates/published.md` into `published/` and fill in the link.

## What not to put here

Raw and exported video files are too big for GitHub, so `.gitignore` skips them.
Keep those in Google Drive, an external drive or your editing software's project folder.
